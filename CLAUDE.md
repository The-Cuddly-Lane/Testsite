# Working rules for this repo

- This repo (`The-Cuddly-Lane/Testsite`) is where all changes to The Cuddly Lane staff app are made, unless Rafael explicitly says otherwise.
- Do not push to or open pull requests on `The-Cuddly-Lane/thecuddlylane-crm` (the live app) unless Rafael asks for it in that conversation.
- Testsite is only used by Rafael's team for now, so changes may be pushed and merged into `main` straight away (Rafael, 22 Nov 2026). Still open a PR with a short description so there is a record, then merge it.
- The app talks to a real Google Sheet with customer data. Never commit keys, the service-account JSON, spreadsheet data or customer details.
